DODGE HOODY — เว็บไซต์พร้อมขึ้น Vercel (16 ไฟล์ ทุกไฟล์เล็กกว่า 3MB)

1. แตกไฟล์ zip จะได้โฟลเดอร์ dodge-hoody
2. GitHub: สร้าง repository ใหม่ → กด "uploading an existing file"
   เปิดโฟลเดอร์ dodge-hoody เลือกทุกอย่างข้างใน แล้วลากไปวาง → Commit changes
   (อย่าลากไฟล์ .zip ขึ้นไป)
3. Vercel: Add New → Project → Import repo นี้ → Framework Preset: Other → Deploy

ไฟล์ในโฟลเดอร์ assets คือภาพผลงานทั้งหมดที่รวมไว้ อย่าเปลี่ยนชื่อไฟล์
